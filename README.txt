GA4 + GTM
---------
The website is ready for analytics, but no tracking ID is activated yet.

Recommended approach:
1. Create a Google Tag Manager container.
2. Replace GTM-XXXXXXX in index.html with the real GTM Container ID.
3. Install GA4 through GTM.
4. Create GA4 events/conversions for:
   - whatsapp_click
   - consultation_click
   - quote_button_click
   - quote_form_submit
5. Test with GTM Preview / Tag Assistant before publishing.

IMPORTANT:
Do not activate both direct GA4 and GA4 through GTM unless there is a deliberate reason,
otherwise page views can be counted twice.
